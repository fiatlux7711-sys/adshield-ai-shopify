1. A qualified lawyer must review each document.
2. Every `[BRACKETED]` placeholder must be completed.
3. Each factual claim must be re-checked against what the shipped code actually
   does — these drafts were written against the code as of the commit that
   added them, and the app is still changing.
4. Rename from `*.draft.md` only once 1–3 are complete.

## Standing constraints

- Never state or imply that AdShield AI determines legal compliance, grants
  legal approval, or replaces legal counsel.
- Never promise "100% compliance" or an unqualified guarantee.
- Never publish a security, backup, uptime, or retention claim that is not
  actually implemented and verified.
- Never place personal addresses, banking details, card data, tax IDs,
  passwords, or secrets in this repository. Owner legal identity goes in these
  documents only when the exact entity name is supplied.
